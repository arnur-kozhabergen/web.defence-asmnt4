# Assignment 4: Forms and Validation

This project contains simple contact and registration forms made with HTML and Bootstrap.

Pages: `index.html` is the contact form, `html-validation.html` checks browser validation, `bootstrap-form.html` shows Bootstrap form styling, `bootstrap-validation.html` shows validation feedback, and `registration.html` contains the registration form.

The registration form checks required fields, email format, password length, matching passwords, gender, and country. The forms are examples and do not save data.

Open `index.html` in a browser to view the project. Bootstrap loads from the internet.
